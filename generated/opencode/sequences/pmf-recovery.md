# pmf-recovery

Runs a PMF recovery loop across measurement, support signal, churn diagnosis, retention, growth, and experiments.

## Entrypoint
- co-founder

## Steps
1. north-star-definer
2. pmf-signal-reader
3. support-insights-reader
4. churn-diagnostician
5. retention-loop-designer
6. growth-loop-builder
7. experiment-planner
8. weekly-founder-review
9. compound

## Primary outputs
- north-star.md
- pmf-assessment.md
- support-insights.md
- churn-diagnosis.md
- retention-loop.md
- growth-loop.md
- experiment-plan.md
- weekly-review.md

## Human-facing response (required)
Before or alongside any file updates, give the founder a short chat answer first:
- **Bottom line:** the direct verdict or useful answer in 1-2 sentences
- **Do this now:** the single next action plus up to 3 concrete steps
- **Details saved:** list only the artifact paths you created or updated
Keep the chat response under 150 words unless the founder asks for detail. Do not paste full markdown artifacts into chat; files are the durable record for agents.

## Success signals
- founder_has_a_clear_pmf_recovery_plan

## Operating notes
# pmf-recovery

Use this when traction is ambiguous, retention is weak, or churn needs a real diagnosis.

Flow:
1. define the metric that matters
2. read PMF signal honestly
3. use support and churn to explain the signal
4. redesign retention before forcing growth
5. choose one experiment and lock the weekly learning loop
6. Capture the learning with compound so the next cycle starts smarter

The goal is not optimism. The goal is a grounded plan for what to improve next.
