How it works.

It gives your agent a repeatable operating loop for startup work, then saves the useful parts as company memory.

  1. Start with co-founderIt reads company memory, identifies the current bottleneck, and recommends one useful next move.
  2. Run the right workflowValidation, customer hypothesis, MVP scope, launch, pipeline, PMF, support, or weekly focus.
  3. Close with compoundIt captures what changed so the next session starts with better context.

The chat stays short.

The founder gets the bottom line. The agent keeps the supporting markdown as durable memory.
