# Coding Host Priority

Founder Skills OS currently prioritizes these coding-agent hosts:

1. pi
2. Codex
3. OpenCode
4. OpenClaw
5. Hermes

Chat prompt bundles currently target ChatGPT.

## Current priority

- Keep Codex global skills discoverable as `$skill-name`.
- Keep pi skill bundles simple and nested under the generated skill directories.
- Keep OpenCode and OpenClaw project installs routed through `AGENTS.md`.
- Keep Hermes global install discoverable through its skills directory.
- Keep all hosts agent-agnostic and tied to the same source skills.
