# Homepage positioning

## Core positioning

Founder Skills is Compound Engineering for the non-technical work of building a startup.

It gives coding agents reusable workflows for the work around the code: choosing ideas, validating customers, scoping products, planning launches, reading PMF signals, and keeping focus.

## Hero

**Compound startup work for your coding agent.**

Founder Skills helps your agent move from idea to validation, product scope, launch, PMF, and weekly focus — with artifacts that make every next cycle easier.

## Short description

AI skills that make each unit of startup work easier than the last.

## Philosophy

**Each unit of startup work should make subsequent units easier — not noisier.**

Most early-stage work creates scattered notes and context resets. Founder Skills turns that work into reusable artifacts:

- customer hypotheses
- problem validation reports
- MVP briefs
- implementation plans
- launch plans
- PMF assessments
- weekly reviews

The point is not ceremony. The point is leverage. Better artifacts make better next decisions.

## Homepage sections

### Why it works

Reads the state. Produces the artifact. Routes the next move.

Founder Skills keeps startup context alive across sessions so each agent does not have to rediscover the company from scratch.

### Start here

Co-founder is the default starting point. It reads state and artifacts, identifies the current bottleneck, and routes into the most useful next skill or sequence.
